# Ultimate Dish

中世風異世界の農村を舞台にした「料理で攻略する」RPG／料理／シミュレーションの縦切り試作。
戦闘の代わりに **料理を作る → 数値評価 → クエストで使う → 図鑑に登録** のループを検証する。

## 動かす

```
npm install
npm run dev      # 開発サーバ
npm test         # 評価ロジックのユニットテスト
npm run build    # 型チェック + 本番ビルド
```

## 主な仕様メモ

- **生成キー** `UD1|食材(ソート済)|工程(順序付き)|チェックサム`。同じキーから同じレシピ・同じ評価が再現される。チェックサムは名前の言い回しやプレースホルダー画像のシードにも使う（将来のAI画像シード候補）。
- **派生料理** 各料理は `id` と `parentDishId` を持つ。図鑑の「派生を作る」で元レシピを引き継いで作り直せる。
- **将来の料理ギルド用** `isPublic`, `generationKey`, `parentDishId`, `guild.{favorites,reproductions}`。系統樹の太さ = 再現成功数 + 派生数（`parentDishId` から集計）。
- **器具は次の調理法に効く**：魔石炉=加熱の精密制御（低温調理はこれが無いと生焼け扱い）、時熟壺=時間系工程を1.5倍、香封鍋=香りを逃さない。
- **香りのスパイスは加熱で半減**するため、入れる順番に意味がある。
- **解放**：スパイス2種と魔石炉は最初から使える。依頼1達成で時熟壺、依頼2達成で香封鍋。
- **評価**（`src/game/evaluation/rating.ts`）：8軸 → 基礎総合点（美味しさのみ2倍の重み）→ 突出ボーナス → 固定閾値ランク → 最低条件。
  - ランク閾値：D 0／C 42／B 55／A 65／S 75／Legendary 85
  - 突出ボーナス：90以上の軸ごとに称号（例：やみつき→「魔性の味」）と総合点+2（上限+4）
  - 最低条件：A以上は美味しさ50以上、Sは美味しさ65以上かつ全軸25以上、Legendaryは美味しさ80以上かつ全軸40以上。満たさなければ満たせるランクまで下がる。生焼けはC止まり。

## Phase 2（工程調理・料理人育成）

| 場所 | 役割 |
| --- | --- |
| `src/game/chef/` | 能力値（初期配分・逓減カーブ `eff`）、レベル・経験値カーブ |
| `src/game/process/simulate.ts` | ライン制の工程シミュレーション（素材投入・調理・魔導具・挽回・合流・盛り付け、工程ごとの成功判定、並列時間） |
| `src/game/process/buildProcessDish.ts` | 工程 → 料理（既存8軸評価＋工程品質＋流派＋仕上げ補正）、生成キーv2 |
| `src/game/inventory/` | 在庫スタック・保存場所・時間変化（劣化／腐敗／熟成／保存） |
| `src/game/school/` | 流派の切替・合成 |
| `src/game/finish/` | 仕上げ入力の矛盾チェック（軽微＝自動補正、重大＝警告）と小補正 |
| `src/game/world.ts` | 時間経過・休息・購入・調理完了（在庫/MP/耐久の消費、経験値・熟練） |
| `src/data/phase2.ts` | 魔導具ルール、工程の基準時間・成功率、挽回工程、スキル、流派 |

- **生成キー**（料理設計）と**調理シード**（その1回の結果）は別。各工程は乱数を必ず2つ消費するため、後から工程を足しても既に判定した工程の結果は変わらない。
- 能力値の効果はすべて `eff(x) = x/(x+30)` 系の飽和カーブを通すので、Lv・能力9999でも成功率や工程数は有限。
- 内部時間の単位は「日」（実数）。

## Phase 3（1日の商売ループ）

通常プレイ：**厨房 → レシピ調理**（レシピ選択 → 食数 → 不足素材の一括購入 → 調理開始 → 途中判定・挽回 → 仕上げ → 完成）→ **販売**（総菜販売の値付け・レシピ契約）→ **1日終了** → 日報。
自由調理（Phase 1）と上級調理（Phase 2のライン制）は厨房のタブに残しています。

| 場所 | 役割 |
| --- | --- |
| `src/data/recipes.ts` | レシピ定義（素材・調味料・難度・時間・体力・魔導具相性・販売タグ・内部工程テンプレート） |
| `src/data/commerce.ts` | 客層・時間帯・地域・店 |
| `src/game/commerce/simpleCook.ts` | 食数のまとめ効率（`batchScale`）、不足計算と一括購入、レシピ調理（裏でPhase 2の工程判定を使用）、挽回、完成 |
| `src/game/commerce/sales.ts` | 推奨価格、時間帯×客層×価格×流行×知名度の需要、1日販売 |
| `src/game/commerce/contracts.ts` | レシピ契約（歩合・期間・日次収入） |
| `src/game/commerce/day.ts` | 1日終了（販売・契約・売れ残り・在庫劣化・睡眠・維持費・知名度・流行）と日報 |
| `src/services/customerVoice.ts` | 客の声（テンプレート。将来の食リポAIに差し替え可能） |

- 体力：最大値は強靭とLvで決まる。30%未満で成功率低下・時間増加・大失敗増。体力を超える量も作れるが、超過分だけ大きく不利になる。
- レベルアップ時のMP全回復は廃止。

## Phase 4（食べる・食リポ・料理勝負）

- **食遍歴**：最初に約5問＋自由記入で、あなたの食経験から好み（味・香り・食感・文化的馴染み）を作る。料理人画面に「食の好み」として一部表示。
- **食べる**：完成した料理を1食食べると、料理の絶対評価とは別に、あなたの好み・馴染み・空腹・疲労・栄養状態を加味した食体験になる（見た目→香り→最初の一口→食感→味の広がり→後味→満足感）。
- **食リポ**：一問一答＋自由記入で記録。好みは食べた料理の傾向へ少しずつ動く（1食あたり最大0.04）。
- **料理勝負**（勝負タブ）：ガルドとの腕試し（審査1人）→ 再戦（肉料理）／収穫祭の一皿勝負（審査3人、テーマ・必須食材・禁止食材・制限時間・食べる人の条件つき）。相手は候補レシピからテーマと審査員を見て選び、成功・失敗判定つきで調理する。採点は「審査員ごとの食体験50%＋テーマ適合25%＋料理の総合点25%」。何度でも再戦でき、勝つほど相手の技術が上がる。
- 審査員情報は知名度と対戦歴に応じて段階的に見える（噂 → 好み → 苦手・冒険度 → 当日の体調）。

| 場所 | 役割 |
| --- | --- |
| `src/types/eating.ts` | EaterProfile（プレイヤー・NPC・審査員共通）、食体験、勝負の型（報酬・特殊ルールは将来用の枠のみ） |
| `src/data/foodStory.ts` / `src/game/eating/` | 食遍歴の質問、プロフィール生成、食体験の計算、嗜好の学習 |
| `src/services/tastingReport.ts` | 食リポ文（テンプレート。AI文章生成に差し替え可能） |
| `src/data/battles.ts` / `src/game/battle/battle.ts` | 審査員・相手・勝負の定義と判定 |

## Phase 5（レシピ習得・熟練度・派生）

- **レシピの状態**：未知 → 発見済み（知っている）→ 試作可能（条件を満たした）→ 習得済み。最初は村の家庭料理3品が習得済み。厨房の「レシピ帳」で状態・熟練段階・数値・次段階の効果・条件の過不足・自作／親レシピが見える。
- **習得経路**：
  - 村の人：宿屋の女将ハンナから「女将の林檎キャベツ酢漬け」（煮る2回・知識10）
  - 書庫：村の書庫「古い保存食の記録」から「古記録の塩漬け干し肉」（Lv2・猪肉を1回料理）
  - 勝負の報酬：ガルドとの腕試しに勝つと「ガルド家の焼き林檎蜂蜜がけ」（流派・流派熟練3）
  - 派生：自分の調理履歴から生まれる着想（下記）
- **試作**：通常のレシピ調理と同じ。失敗が残らず、ランクD以外で仕上がれば習得。失敗しても知識は残る。
- **熟練度（レシピごと0〜100）**：見習い0／習熟25／熟練50／達人80。調理ごとに上がり、大成功・まとめ作り・高評価で少し多く、上限に近いほど伸びにくい。効果は控えめ（100で成功率+6%・時間/体力−15%）。
- **派生の着想**：調理3回・熟練度25以上で、そのレシピの履歴（ハーブを添えた・魔石炉を使った・北方流派で作った・大成功を重ねた・10食以上作った）から着想が出る。自動登録はされず、「この派生をレシピとして残す」を選び、名前（候補3つ＋自由入力）・説明・由来を付けたときだけ自作レシピになる。自作レシピは親レシピ（`parentRecipeIds`）を持ち、通常どおり調理・販売・勝負に使える。
- レシピを失う・封印する等の特殊勝負は未実装（`RecipeProgress` に将来用の拡張余地のみ）。

| --- | --- |
| `src/types/learning.ts` | レシピの状態・習得元・履歴・派生の着想 |
| `src/game/learning/recipeBook.ts` | 組込み＋自作レシピの参照、条件判定、試作・習得、熟練度、派生の着想と採用 |
| `src/data/derivations.ts` / `src/data/learningSources.ts` | 派生ルール、村の人・書庫の定義 |
| `src/components/RecipeBook.tsx` | レシピ帳・詳細・習得結果・着想の採用画面 |

## Phase 6（相棒・仲間・関係・共同料理）

- **特殊相棒**：食遍歴のあと、仲間タブ（または村の「不思議な気配」）で出会う。短い性格の選択（慎重/即断・寡黙/おしゃべり・理屈/感覚・保守/冒険、作り手/食べ手。食遍歴と能力から2つは推定）から、あなたと正反対の候補を3体提示する（灰羽の梟使い魔＝評者・味付け／炉火の火蜥蜴＝火加減・焼き物／瓶詰めの魔導人形＝漬け・干し・魔導具）。役割・性格・食の好み・強みを反転して補完し、カードに「あなたが慎重だから、この相棒は思いついたらすぐ動く」のような理由を出す。「誰も選ばない」も選べ、相棒なしでもすべて遊べる。
- **相棒あり／なし**：ありの場合は相棒との会話・試食（「○○に食べてもらう」）・共同料理・食の記憶・関係の成長が出る。なしの場合はそれらのUIを出さず、村の人との関係が中心になる。
- **通常の仲間候補**：猟師の娘ミラ（猟場。好感25・あなたの猪肉の香草焼きを食べた・勝負に一度勝つ）、パン焼きのテオ（パン焼き窯。信頼30・一緒に料理した・食の相性55）。話す・ふるまう・手伝いで関係が進み、条件を満たすと「仲間に誘う」で加入する。
- **関係**：人物ペアごとに好感・信頼・食の相性・わだかまり、一緒に食べた/作った回数、食の記憶（重要なもの最大5件）を持つ。主人公↔NPC だけでなく相棒↔仲間など仲間同士にもあり、食事や共同料理で少しずつ変わる。表示は段階名（距離がある/顔見知り/親しい/信頼している）と傾向（友好的/競争的/息が合う）で、数値は詳細画面に出す。
- **共同料理**：主担当1人＋補助役（型は複数補助に対応）。補助役の腕・得意分野と料理の合い方・2人の信頼/好感/わだかまりで成功率に小さな補正（合計 −4%〜+8%）と、時間・体力の軽減。相棒や仲間は自分の得意料理を主担当で作れる（あなたは補助）。

## Phase 7（旅・地域の食文化）

> **固定データの原則**：地理・地域・町・街道・文化圏・地域料理の基礎・流派の世界設定は、手で作った固定データです（自動生成しません）。自動生成は料理まわり（プレイヤー料理・派生料理・料理の表現）に限ります。旅のロジックは座標を持たないグラフ（地点・接続・日数・開放条件・文化圏）で動くため、表示は文章でも2D地図でも差し替えられます。

- **地点**：麦畑の村 →（1.5日）川沿いの市場町 →（2日）海辺の港町／（2.5日）山岳の高地集落。最初は市場町だけ行け、一度着くと港町と山岳が開く（順番は自由。港町⇄山岳は市場町経由で自動ルート）。
- **旅**：選ぶのは行き先と同行者（相棒・加入済みの仲間）だけ。出発前に「片道○日・携行食○食（自動）・生鮮品の鮮度の落ち方」を表示。移動は既存の時間進行（在庫の劣化・MP回復・維持費）をそのまま使う。旅の夜は少し眠れ、作り置きの料理は一晩ごとに鮮度が落ちる（既存の夜の規則と同じ）。ごくまれに雨で半日足止め。
- **携行食**：1人1日1食。保存食タグの料理を古い順に使い、足りない分はその土地の値段で自動購入。お金が足りなくても出発でき、その分は空腹で体力が少し減るだけ。
- **同行者**：同行した全ペアの `traveledTogether` が1増え、信頼は+1だけ（旅だけで大きくは変わらない）。
- **地域の市場**：これまでの固定価格を基準に、地域ごとの倍率で地元品（安い）・輸入品（高い）・売っていない品が分かれる。村は従来どおり同じ値段。厨房の不足素材購入も現在地の値段・品ぞろえに従う。
- **地域料理**：各地域3品（`originRegionId`・`cultureTags` 付きの RecipeDef）。現地で「作り方を教わる」と Phase 5 の「知っている」になり、条件を満たせば試作 → 習得。
- **地域料理観**：鮮度・保存・香り・滋養・洗練・安さ・濃厚さ・塩（0〜1）。表示は「この土地では○○と○○を重んじる」だけ。地域理解度は置き場（`regionKnowledge`）のみで、数値は出さない。
- **独自流派の成立条件（判定のみ）**：2地域以上を訪れる・異なる2地域以上の地域料理を習得（計2品以上）・派生レシピを1つ以上残す・料理を10回以上作る・相棒か仲間と1回以上共同料理。満たすと「独自流派を興せるだけの経験が集まりつつある」と表示し、内訳は現在地の「🏯 流派」と料理人の流派タブで見られる。命名・理念・技法・継承は今後。
