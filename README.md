# Ultimate Dish

中世風異世界の農村を舞台にした「料理で攻略する」RPG／料理／シミュレーションの縦切り試作。
戦闘の代わりに **料理を作る → 数値評価 → クエストで使う → 図鑑に登録** のループを検証する。

## 動かす

```
npm install
npm run dev      # 開発サーバ
npm test         # 評価ロジックのユニットテスト
npm run build    # 型チェック + 本番ビルド
```

## 構成

| 場所 | 役割 |
| --- | --- |
| `src/data/` | 食材21種・調理法10種・異世界スパイス2種（品質向上系：焔胡椒／身体効果系：癒樹の根）・特殊器具3種・食べ手・クエスト・村の施設 |
| `src/game/cooking/` | レシピ → 料理状態（`cook.ts`）、料理名（`naming.ts`）、生成キー（`generationKey.ts`）、料理データ組み立て（`buildDish.ts`） |
| `src/game/evaluation/` | 8軸の絶対評価（`absolute.ts`、美味しさは `deliciousness.ts`）と食べ手ごとの体験評価（`experience.ts`） |
| `src/game/quest/` | クエスト判定 |
| `src/services/` | 文章・画像生成のサービス層（現在はmock。AI接続時はここだけ差し替え） |
| `src/state/` | `useReducer` + Context の単一ストア（メモリのみ。再読み込みで消える） |
| `src/pages/`, `src/components/` | UI |

ゲームロジック（`src/game`）は純関数でReactに依存しない。

## 主な仕様メモ

- **生成キー** `UD1|食材(ソート済)|工程(順序付き)|チェックサム`。同じキーから同じレシピ・同じ評価が再現される。チェックサムは名前の言い回しやプレースホルダー画像のシードにも使う（将来のAI画像シード候補）。
- **派生料理** 各料理は `id` と `parentDishId` を持つ。図鑑の「派生を作る」で元レシピを引き継いで作り直せる。
- **将来の料理ギルド用** `isPublic`, `generationKey`, `parentDishId`, `guild.{favorites,reproductions}`。系統樹の太さ = 再現成功数 + 派生数（`parentDishId` から集計）。
- **器具は次の調理法に効く**：魔石炉=加熱の精密制御（低温調理はこれが無いと生焼け扱い）、時熟壺=時間系工程を1.5倍、香封鍋=香りを逃さない。
- **香りのスパイスは加熱で半減**するため、入れる順番に意味がある。
- **解放**：スパイス2種と魔石炉は最初から使える。依頼1達成で時熟壺、依頼2達成で香封鍋。
- **評価**（`src/game/evaluation/rating.ts`）：8軸 → 基礎総合点（美味しさのみ2倍の重み）→ 突出ボーナス → 固定閾値ランク → 最低条件。
  - ランク閾値：D 0／C 42／B 55／A 65／S 75／Legendary 85
  - 突出ボーナス：90以上の軸ごとに称号（例：やみつき→「魔性の味」）と総合点+2（上限+4）
  - 最低条件：A以上は美味しさ50以上、Sは美味しさ65以上かつ全軸25以上、Legendaryは美味しさ80以上かつ全軸40以上。満たさなければ満たせるランクまで下がる。生焼けはC止まり。

## Phase 2（工程調理・料理人育成）

| 場所 | 役割 |
| --- | --- |
| `src/game/chef/` | 能力値（初期配分・逓減カーブ `eff`）、レベル・経験値カーブ |
| `src/game/process/simulate.ts` | ライン制の工程シミュレーション（素材投入・調理・魔導具・挽回・合流・盛り付け、工程ごとの成功判定、並列時間） |
| `src/game/process/buildProcessDish.ts` | 工程 → 料理（既存8軸評価＋工程品質＋流派＋仕上げ補正）、生成キーv2 |
| `src/game/inventory/` | 在庫スタック・保存場所・時間変化（劣化／腐敗／熟成／保存） |
| `src/game/school/` | 流派の切替・合成 |
| `src/game/finish/` | 仕上げ入力の矛盾チェック（軽微＝自動補正、重大＝警告）と小補正 |
| `src/game/world.ts` | 時間経過・休息・購入・調理完了（在庫/MP/耐久の消費、経験値・熟練） |
| `src/data/phase2.ts` | 魔導具ルール、工程の基準時間・成功率、挽回工程、スキル、流派 |

- **生成キー**（料理設計）と**調理シード**（その1回の結果）は別。各工程は乱数を必ず2つ消費するため、後から工程を足しても既に判定した工程の結果は変わらない。
- 能力値の効果はすべて `eff(x) = x/(x+30)` 系の飽和カーブを通すので、Lv・能力9999でも成功率や工程数は有限。
- 内部時間の単位は「日」（実数）。
